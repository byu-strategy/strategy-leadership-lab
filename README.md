# Strategy Leadership Lab (STRAT 490R)

Quarto book for Strategy Leadership Lab, BYU Marriott School of Business.

The site builds automatically from `main` via GitHub Actions and deploys to GitHub Pages
from `docs/`. Do not render locally; use `quarto preview` while writing.

Heavy materials and student data live in OneDrive and are reached through the gitignored
`_materials` and `_private` symlinks.
